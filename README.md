## Selected projects

### [Indoor Drone Gas Flight Demo](https://github.com/sefatasdemir22/indoor_drone_gas_flight_demo)
Graduation-project implementation for autonomous indoor gas-inspection missions in a GPS-denied corridor-and-room environment. The system uses ROS 2, PX4 SITL, Gazebo Classic, MAVSDK, and Python, with LaserScan-based room-opening detection, multi-room inspection, return to a local home reference, and staged landing.

### [Dormitory Laundry Reservation and Management System](https://github.com/sefatasdemir22/YurtCamasirhaneOtomasyonu)
A full-stack university course project built with React, Material UI, Node.js, Express, PostgreSQL, REST APIs, JWT authentication, Jest, and Docker Compose. It includes student and administrator workflows, reservation rules, machine management, and fault reporting.

### [Abonelik Takip](https://github.com/sefatasdemir22/abonelik-takip)
An actively developed Android-first Flutter application for tracking personal and shared subscriptions, recurring payments, and related financial workflows.

### [Orman Yangını Tespit Sistemi](https://github.com/sefatasdemir22/Orman-Yangini-Tespit-Sistemi)
A wildfire image-classification project using transfer learning with MobileNetV2, Keras, and a Gradio-based interface.
